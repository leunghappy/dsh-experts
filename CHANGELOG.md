# 更新记录 · Changelog

## 0.3.0

- 新增 DSH 标准中英文展示元信息、详情页、配置样例和 GitHub 源码构建脚本。
- 管理页、会话选择器及切换反馈跟随 DSH 的语言设置。发布索引从同一份包清单读取版本和兼容范围。
- Adds DSH display metadata, user guides, configuration examples, and a GitHub source build for Chinese and English.
- The manager, picker, and switch feedback follow the DSH language setting. The plugin index uses the bundle version and compatibility range.

## 0.2.0

- 增加专家管理和会话专家切换，处理纯文本草稿复制、目标已有草稿和附件保留。
- Adds expert management and chat expert switching, including plain-text draft handling and draft conflict protection.
