# 专家

在 DeepSeek Harness 桌面端，专家是已经配置到 DSH 的 Agent Preset。专家的角色、工具与技能沿用该预设。插件提供分类目录和会话选择器。

## 使用方法

1. 在侧栏打开「专家管理」，用卡片浏览专家的头像、名称和简介。新建分类后，可为同一个专家添加多个标签。
2. 在会话输入框底部、权限控件右侧打开专家选择器。左栏搜索分类，右栏搜索当前分类下的专家名称或别名。悬停或聚焦候选可看简介。
3. 在空白会话选择专家，等按钮显示目标专家后再发送。已开始的会话会打开当前工作区中的目标专家会话。

纯文本草稿可预填到空稿目标，原会话保留副本。若目标已有草稿，可以返回原会话或复制这次的文本。附件和结构化引用留在原会话。

## 配置示例

插件自动读取当前 DSH 实例中的 Agent Preset。新安装预设后，使用「刷新本地专家」。分类和标签在管理页修改，保存在当前客户端。插件维护者可以在 `src/expert-metadata.json` 为已有预设补充可选的展示名称、简介和搜索别名。修改后重新构建或安装更新版本。

```json
{
  "your-preset-id": {
    "name": { "zh": "SQL 审查专家", "en": "SQL review expert" },
    "description": { "zh": "审查 SQL 的正确性和性能。", "en": "Reviews SQL for correctness and performance." },
    "aliases": ["SQL审查", "SQL review"]
  }
}
```

将 `your-preset-id` 换成已有预设的实际 ID。`name` 和 `description` 也接受单个字符串。省略时使用 DSH 提供的内容。两种语言的别名都可以搜索。若设置 `avatar`，其值为客户端可访问的图片 URL。
